# Customer Shopping Behavior Analysis
Customer shopping behavior analysis using Python (Pandas), MySQL, and Power BI to uncover purchasing patterns and customer insights.

# Project Overview
This project analyzes customer shopping behavior to uncover purchasing patterns, customer segments, and factors influencing revenue.
The analysis was performed using Python (Pandas) for data cleaning, MySQL for data analysis, and Power BI for interactive visualization.

The goal of this project is to demonstrate an end-to-end data analysis workflow, from raw data processing to actionable business insights.

# Tools & Technologies Used
- **Python** – Data cleaning and preprocessing
- **Pandas** – Data manipulation and analysis
- **MySQL** – Data querying and analysis
- **Power BI** – Dashboard and data visualization
- **Jupyter Notebook** – Analysis environment

# Project Workflow
**1. Data Cleaning (Python & Pandas)** 
 - Loaded dataset into Jupyter Notebook
 - Checked missing values and data types
 - Filled missing review ratings using category median
 - Prepared dataset for analysis

**2. Data Analysis (MySQL)**
- Wrote SQL queries to analyze customer purchasing behavior
- Used CTEs and window functions for advanced analysis

**3. Data Visualization (Power BI)**
- Built an interactive dashboard to visualize insights
- Created charts for revenue trends, customer segments, and product performance


# Key Business Questions Answered
- What is the total revenue generated by male and female customers?
- Which customers used discounts but still spent more than the average purchase amount?
- What are the top 5 products with the highest average review rating?
- Do subscribed customers spend more than non-subscribers?
- Which products have the highest percentage of discount usage?
- How can customers be segmented into New, Returning, and Loyal groups?
- What are the top 3 most purchased products in each category?
- Are repeat buyers more likely to subscribe?
- Which age groups contribute the most revenue?

# Key Insights
- Certain product categories consistently receive higher review ratings, indicating strong customer satisfaction.
- Subscribed customers generate higher total revenue, suggesting subscription programs encourage spending.
- A small number of products account for a large share of purchases, showing strong product demand.
- Customers with more previous purchases tend to become loyal repeat buyers.
